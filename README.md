# CSE473 Labs

Student-facing notebooks for **CSE473: Computational Intelligence** (Mechatronics Engineering and Automation Program).

## Contents (`content/`)

**Lab Assignments** (submit via the course portal — auto-graded):
- `lab01_assignment_solving_linear_systems.ipynb` — linear systems with NumPy
- `lab02_assignment_pandas_iris.ipynb` — data analysis with pandas (Iris)
- `lab03_assignment_contour_plots.ipynb` — contour plots with matplotlib
- `lab04_assignment_nonlinear_equations.ipynb` — nonlinear equations with scipy.optimize
- `lab05_assignment_double_moon_binary.ipynb` — double moon, binary classification
- `lab06_assignment_double_moon_multiclass.ipynb` — four-category classification
- `assignment_ga_optimization.ipynb` — genetic algorithm (extra practice)

**Lab Activities** (interactive learning labs, ~30–60 min each — open in JupyterLite):
- `lab01_learning_linear_systems.ipynb` … `lab06_learning_multiclass_classification.ipynb`

## JupyterLite site

The `main` branch is automatically built into an interactive JupyterLite site
(WebAssembly Python in the browser — no server needed) and deployed to GitHub Pages:
**https://cse474s.github.io/cse473-labs/lab/index.html**

The course platform embeds these notebooks via that URL. GPU-heavy assignments
(Labs 05/06) open in Google Colab instead.
